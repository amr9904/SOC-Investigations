# SOC Investigations

A collection of incident response reports, threat hunting investigations, and SOC analysis write-ups focused on identifying, analyzing, and responding to cyber threats across enterprise environments.

## Reports

This repository contains hands-on security investigations covering:

* Phishing and malware analysis
* SIEM-based investigations (Splunk & IBM QRadar)
* Alert triage and incident response
* Threat hunting and IOC analysis
* Windows event and Sysmon analysis
* Lateral movement and persistence detection
* Network traffic and log correlation
* MITRE ATT&CK mapping and threat intelligence
