# SOC Investigations

A collection of incident response reports and SOC analysis write-ups.

## Reports

- **Lumma Stealer — ClickFix Phishing Campaign**
  Investigated a ClickFix phishing campaign delivering Lumma Stealer via obfuscated PowerShell and mshta.exe LOLBin abuse. Extracted IOCs and mapped TTPs to MITRE ATT&CK.
  `MITRE: T1566.002 | T1218.005 | T1027 | T1059.001`

- **Splunk BOTSv2 — 100 & 200 Series**
  Multi-stage investigation covering insider threat (Amber Turing), web application attacks (SQLi via updatexml, XSS session hijacking), and vulnerability scanning. Full SPL queries and MITRE mapping included.
  `MITRE: T1213 | T1048 | T1190 | T1595.002 | T1185 | T1136`
